# TODO 2026-10-07: Output-Dateien im Chat anzeigen

## Ziel

Erzeugte Dateien (via `Output`-Tool) unterhalb der Chat-Antwort als Liste mit
View/Download-Icon rendern. Nutzer muss NICHT in den Results-Ordner wechseln.

## Taki liefert schon

`chatAskResponse.tool_trace[]` enthält alle Output-Events:

```json
{"tool": "Output", "method": "output", "path": "vorbericht-2026/Vorbericht_2026_2027.md", "chars": 46921, "file_size": 46921}
{"tool": "OutputMkdir", "method": "output-mkcol", "path": "vorbericht-2026"}
```

Keine Taki-Änderung nötig.

## Noetron (chat-with-file Extension)

### 1. SSE-Stream: Output-Events mitschneiden

Im Chat-Panel (oder der Component die den Stream parsert):
- Beim Empfangen von `tool_trace`-Einträgen (bzw. SSE-Events) mit `method === "output"`:
  - `path`, `chars`, `file_size` speichern
  - In ein Array `outputFiles: {path, size}[]` pushen

### 2. UI: Datei-Liste unter der Antwort

Nach Stream-Ende, wenn `outputFiles.length > 0`:

```
[icon: file]  vorbericht-2026/Vorbericht_Haushaltsplan_2026_2027.md  (45.8 KB)
```

- View-Icon: öffnet die Datei im OpenCloud Viewer (Datei-Route via share-URL)
- Download-Icon: trigger download via share-URL

Die Base-URL für die Dateien kommt aus `context.output.share` (Token+Password
→ WebDAV-Share-URL die Noetron schon beim Request-Setup kennt).

### 3. Style

Konsistent mit "Hide file access" (Tool-Trace-Akkordeon). Eigener Block:
```
▾ Erzeugte Dateien (1)
  [file] Vorbericht_Haushaltsplan_2026_2027.md  45.8 KB  [view] [dl]
```

Platzierung: unterhalb der Antwort, über "Hide file access".
